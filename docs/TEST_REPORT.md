## Дополнительные проверки

- Редактирование имени/должности, архив, поиск по кириллице, восстановление:
  API и браузерный профиль проходят.
- Архивирование при работающем таймере, изменение/удаление активной записи: 409. Старт архивного сотрудника: 422. Отсутствующий UUID: 404.
- Некорректная дата, обратный/слишком длинный период, отрицательная страница,
  пустая/длинная задача и обратный интервал: 400.
- Активные сессии исключены из сумм. Многодневная сессия: сумма дневных значений
  равна сумме отчёта. Нулевая сессия на полуночи учитывается в одном дне с нулевой длительностью.
- Backup → очистка → импорт возвращают UUID и активную сессию. Неверная версия,
  дубли UUID и отсутствующий сотрудник отклоняются без изменения базы.
- Демо-режим: импорт/очистка 403; cross-origin изменение 403; form content-type 415;
  повреждённый JSON 400; неизвестный endpoint 404.
- Отмена остановки не завершает таймер; Esc закрывает несохранённую форму.
- Abort запроса API: сообщение о недоступном сервере, диалог остаётся открыт,
  ложного сохранения нет. В основном сценарии браузерные pageerror отсутствуют.
